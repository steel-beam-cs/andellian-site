# Andellian

The initial Andellian.com homepage, built from the approved homepage blueprint
with Next.js, TypeScript, Tailwind CSS, and the App Router.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Validation

```bash
npm run lint
npm run build
```
